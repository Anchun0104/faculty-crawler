# GitHub 源码包 2.1.0 设计说明

## 目标

为已经完成的 faculty-crawler 更新生成一个可直接上传 GitHub 的独立源码包，同时避免包含运行数据、凭据、本地环境或 Codex 会话文件。

## 版本与内容

- 将唯一版本号来源从 `2.0.0` 升级到 `2.1.0`。
- 包含原有桌面爬虫，以及新增的证据优先工作流入口、Python 包、验证脚本、测试、安装与构建文件、用户文档。
- 更新 `build_release.py`，让确定性发布包包含 `faculty_workflow`、`workflow.py`、`workflow_desktop.py` 和受支持的验证脚本，而不再只包含旧版 `crawler` 与 `ui` 包。
- 增加简明的 `2.1.0` 中文发布说明，涵盖官方二级来源发现、HTML/PDF 缓存解析、local-only 工作流、证据导出、复核重处理，以及跨院系和非人员内容过滤。

## 排除项

GitHub 源码包不得包含 `.git`、`.venv`、`.codex`、`workflow_data`、数据库、抓取快照、生成的表格、日志、缓存、构建输出和 Python 字节码。

## 打包方式

沿用仓库的确定性 `build_release.py`。压缩包使用固定根目录，并同时生成 SHA-256 校验文件和文件清单，使上传范围可审计。

## 验证方式

- 修改发布逻辑前先增加发布包测试。
- 检查压缩包包含新增工作流文件，且不包含任何排除路径或扩展名。
- 运行完整单元测试、Python 编译检查、`git diff --check` 和压缩包内容复核。

## 交付方式

把 ZIP、SHA-256 校验文件、文件清单和中文发布摘要放在 Git 工作区之外的共享目录中。不提交、不推送、不合并，也不删除当前 worktree。
